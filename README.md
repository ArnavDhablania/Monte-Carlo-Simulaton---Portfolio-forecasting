# Monte Carlo Portfolio Simulation

This project uses a Monte Carlo Simulation to model potential future returns of an investment portfolio under uncertainty. The simulation estimates a distribution of outcomes instead of a single prediction, helping evaluate risk, volatility, and the likelihood of outperforming benchmark investments.

**Project Integration Note:** This is Part 2 of a two-part investment pipeline. Instead of running on static data, this risk engine is designed to ingest the live, optimized portfolio weights (including short positions) generated by the **[Black-Litterman Sentiment Optimizer Repo](https://github.com/ArnavDhablania/black-litterman-sentiment-portfolio-optimizer)** via the `data_backups/strategy_report.csv` file.

## Objectives
* Simulate possible portfolio performance over a defined time horizon.
* Estimate risk and uncertainty using repeated random sampling (historical bootstrapping).
* Process negative portfolio weights seamlessly to model active short position hedges.
* Visualize distributions, confidence intervals, and outcome probabilities.
* Provide actionable insights about portfolio risk vs reward.

## Methodology
1. **Load Portfolio Data:** Pulls the sentiment-optimized weights directly from the Black-Litterman CSV report.
2. **Align Tickers:** Uses a tracking mechanism to automatically map weights to historical return data and zero-pad non-optimized assets.
3. **Generate Asset Returns:** Randomly samples historical returns across thousands of trials to compound cumulative growth over a 252-day horizon.
4. **Analyze Results:** Computes expected return, worst-case/best-case outcomes, and 95% Value at Risk (VaR).
5. **Visualize:** Plots the simulated % change paths starting cleanly from a 0% baseline origin.
   - Sharpe Ratio
6. Visualize results using plots and distributions
